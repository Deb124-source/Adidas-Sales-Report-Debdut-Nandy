# Adidas Sales Dashboard 📊

An interactive Power BI dashboard project built to analyze Adidas sales performance across different regions, products, retailers, and time periods. This dashboard helps uncover business insights related to revenue generation, profitability, product performance, and regional sales trends.

## 🚀 Project Overview

This project focuses on transforming raw Adidas sales data into meaningful business insights using Power BI visualizations and KPI analysis.

The dashboard provides:

* Sales trend analysis over time
* Regional performance comparison
* Product-wise sales insights
* Retailer contribution analysis
* Profitability tracking
* Target achievement monitoring
